# Brands assets (staging)

Ready-to-submit assets for the [home-assistant/brands](https://github.com/home-assistant/brands)
repository. Until that PR is merged, the Home Assistant UI and HACS show a
placeholder icon for this integration — the logo is only visible in this
repo's README (`images/logo.png`).

To submit: fork home-assistant/brands, copy `custom_integrations/energy_manager/`
into the fork at the same path, open a PR. Requirements (verified):
icon.png 256×256, icon@2x.png 512×512, optional logo variants, PNG with
transparency preferred (current files use the circular blue background —
acceptable, but a transparent-background variant can be swapped in later).
