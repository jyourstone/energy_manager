The existing `async_setup_entry` creates only the price sensor. Extend it to also create battery sensors when the battery module is enabled.

Update `async_setup_entry`:
```python
async def async_setup_entry(hass, entry, async_add_entities):
    entities = []

    # Core price sensor (always present)
    price_coordinator = entry.runtime_data.price_coordinator
    entities.append(EnergyManagerPriceSensor(price_coordinator, entry))

    # Battery schedule sensors (when battery module enabled)
    battery_coordinator = entry.runtime_data.battery_coordinator
    if battery_coordinator is not None:
        entities.extend([
            BatteryScheduleSensor(battery_coordinator, entry),
            NextChargeSensor(battery_coordinator, entry),
            NextDischargeSensor(battery_coordinator, entry),
        ])

    async_add_entities(entities)
```

**BatteryScheduleSensor(EnergyManagerEntity, SensorEntity):**
- `_attr_translation_key = "battery_schedule"`
- `_attr_icon = "mdi:battery-clock"`
- `unique_id = f"{entry.entry_id}_battery_schedule"`

`native_value` property:
- Returns `self.coordinator.data.current_state` if data is not None, else "unknown"
- Maps internal names for readability: "grid_charging", "discharging", "solar_charging", "idle"

`extra_state_attributes` property:
- Returns dict with:
  - `"schedule"`: list of slot dicts from `coordinator.data.schedule` -- serialize each ScheduleSlot as `{"start": slot.start.isoformat(), "end": slot.end.isoformat(), "price": slot.price, "action": slot.action}`. Max 48 slots (trim if longer).
  - `"charging_slots"`: `coordinator.data.charging_slot_count`
  - `"discharging_slots"`: `coordinator.data.discharging_slot_count`
  - `"target_ems_mode"`: `coordinator.data.target_ems_mode`
  - `"last_calculated"`: `coordinator.data.last_calculated.isoformat()`
  - `"solar_forecast_used"`: `coordinator.data.solar_forecast_used`
- Return empty dict if data is None.
- **IMPORTANT**: Do NOT include full price arrays (already available on PriceCoordinator). Keep attributes compact per Phase 1 lesson (01-05 gap closure removed oversized attributes).

**NextChargeSensor(EnergyManagerEntity, SensorEntity):**
- `_attr_translation_key = "next_charging_slot"`
- `_attr_icon = "mdi:battery-charging"`
- `_attr_device_class = SensorDeviceClass.TIMESTAMP`
- `unique_id = f"{entry.entry_id}_next_charging_slot"`

`native_value` property:
- If `coordinator.data` is not None and `coordinator.data.next_charging_slot` is not None, return the `start` datetime from `next_charging_slot` dict.
- Else return None.

`extra_state_attributes` property:
- If next_charging_slot exists, return `{"price": slot["price"], "end": slot["end"]}`.
- Else return empty dict.

**NextDischargeSensor(EnergyManagerEntity, SensorEntity):**

- `_attr_device_class = SensorDeviceClass.TIMESTAMP`

Same pattern as NextChargeSensor but reads `next_discharging_slot`.
