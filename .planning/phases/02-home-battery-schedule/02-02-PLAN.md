**coordinator.py -- Add BatteryScheduleCoordinator and BatteryScheduleData:**

Add `BatteryScheduleData` dataclass:

```python
@dataclass
class BatteryScheduleData:
    """Output of the battery schedule coordinator."""
    current_state: str  # "idle" | "grid_charging" | "discharging" | "solar_charging"
    schedule: list  # list of ScheduleSlot (from battery_scheduler)
    next_charging_slot: dict | None  # serialized slot dict or None
    next_discharging_slot: dict | None
    charging_slot_count: int
    discharging_slot_count: int
    target_ems_mode: str  # "command_charging" | "max_self_consumption" | "standby"
    last_calculated: datetime
    solar_forecast_used: bool
```

Add `BatteryScheduleCoordinator` class:

```python
class BatteryScheduleCoordinator(DataUpdateCoordinator[BatteryScheduleData]):
```

**Constructor:**
- Accepts `hass`, `entry`, `price_coordinator` (PriceCoordinator instance)
- Sets `update_interval=timedelta(minutes=BATTERY_SCHEDULE_UPDATE_INTERVAL_MINUTES)`
- Sets `always_update=False`
- Stores reference to `_price_coordinator`
- Initializes mutable threshold attributes:
  - `self.charge_threshold: float = DEFAULT_CHARGE_THRESHOLD`
  - `self.discharge_threshold: float = DEFAULT_DISCHARGE_THRESHOLD`
  - `self.max_charge_power_w: float = DEFAULT_MAX_CHARGE_POWER_W`
- These will be updated by NumberEntity instances after setup

**`_async_setup()` method:**
- Chain to PriceCoordinator: `self._unsub_price = self._price_coordinator.async_add_listener(self._handle_price_update)`
- Register cleanup: `self.config_entry.async_on_unload(lambda: self._unsub_price())`
- Optionally register Forecast.Solar state listener if entity configured: use `async_track_state_change_event` with entity from `entry.options.get(CONF_FORECAST_SOLAR_ENTITY)`. Only if entity_id is truthy.
- Register SOC entity state listener for reactive updates: `entry.options.get(CONF_SOC_ENTITY)`

**`_handle_price_update` callback:**
- `self.hass.async_create_task(self.async_request_refresh())`

**`_handle_external_update` callback (for SOC and solar changes):**
- Same as price update: triggers refresh

**`_async_update_data()` method:**
1. Read price data from `self._price_coordinator.data`. If None or no today slots, raise UpdateFailed.
2. Combine today + tomorrow price slots into a single list of dicts: `[{"start": slot.start, "end": slot.end, "price": slot.price} for slot in price_data.today + price_data.tomorrow]`
3. Read current SOC from HA entity state: `hass.states.get(entry.options.get(CONF_SOC_ENTITY))`. Default to 50.0 if unavailable/None.
4. Read solar forecast from HA entity state if configured. Use `_get_solar_forecast_wh()` helper that returns `float | None`. Read the `sensor.energy_production_today` type entity and convert Wh value.
5. Read battery capacity from entry options (`CONF_BATTERY_CAPACITY_KWH`), default to `DEFAULT_BATTERY_CAPACITY_KWH`.
6. Call `build_battery_schedule()` with all parameters, reading thresholds from `self.charge_threshold`, `self.discharge_threshold`, `self.max_charge_power_w`.
7. Convert `BatteryScheduleResult` to `BatteryScheduleData`. Serialize next_charging_slot and next_discharging_slot to dicts (start/end as ISO, price as float, action as str) or None.
8. Map current_action to current_state: "charge" -> "grid_charging", "solar_charge" -> "solar_charging", others pass through.
9. Return BatteryScheduleData.

**Helper `_get_solar_forecast_wh()` method:**
- Reads Forecast.Solar entity state from hass
- Returns `float | None` (None if entity not configured, unavailable, or non-numeric)
- Multiply by 1000 if the entity reports in kWh (check unit_of_measurement attribute)

**Important:** Import `build_battery_schedule` and `BatteryScheduleResult` from `.battery_scheduler`. Import new constants from `.const`.

- `_attr_native_step = CHARGE_POWER_STEP`
- `_attr_native_unit_of_measurement = "W"`

- `unique_id = f"{entry.entry_id}_max_charge_power"`

**Each class implements:**

`async_added_to_hass(self) -> None`:
- Call `await super().async_added_to_hass()`
- `last_data = await self.async_get_last_number_data()`
- If `last_data and last_data.native_value is not None`, set `self._attr_native_value = last_data.native_value`
- Else set `self._attr_native_value = self._default_value`
- Also update the coordinator's corresponding attribute immediately:
  - ChargeThreshold -> `self.coordinator.charge_threshold = self._attr_native_value`
  - DischargeThreshold -> `self.coordinator.discharge_threshold = self._attr_native_value`
  - MaxChargePower -> `self.coordinator.max_charge_power_w = self._attr_native_value`

`async_set_native_value(self, value: float) -> None`:
- `self._attr_native_value = value`
- `self.async_write_ha_state()`
- Update coordinator attribute (same mapping as above)
- `await self.coordinator.async_request_refresh()`
