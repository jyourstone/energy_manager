Create per-car entities (schedule sensor, departure time, target SOC, max charge power) and the time.py platform.

Purpose: These entities make each car visible and configurable in the HA UI.     **time.py** -- Create new platform file:

    Create `custom_components/energy_manager/time.py` with:

    ```python
    """Time platform for the Energy Manager integration.

    Provides per-car departure time entities using TimeEntity with RestoreEntity
    for persistence across restarts. Changing the departure time triggers
    schedule recalculation on the associated car coordinator.
    """

    from __future__ import annotations

    from datetime import time

    from homeassistant.components.time import TimeEntity
    from homeassistant.core import HomeAssistant
    from homeassistant.helpers.entity import EntityCategory
    from homeassistant.helpers.entity_platform import AddEntitiesCallback
    from homeassistant.helpers.restore_state import RestoreEntity

    from .coordinator import EnergyManagerConfigEntry
    from .entity import CarEntity


    async def async_setup_entry(
        hass: HomeAssistant,
        entry: EnergyManagerConfigEntry,
        async_add_entities: AddEntitiesCallback,
    ) -> None:
        """Set up car departure time entities from config entry."""
        for subentry_id, coordinator in entry.runtime_data.car_coordinators.items():
            subentry = entry.subentries[subentry_id]
            async_add_entities(
                [CarDepartureTime(coordinator, entry, subentry)],
                config_subentry_id=subentry_id,
            )
    ```

    `CarDepartureTime(CarEntity, TimeEntity, RestoreEntity)`:
    - `_attr_translation_key = "departure_time"`
    - `_attr_entity_category = EntityCategory.CONFIG`
    - Constructor: super().__init__(coordinator, entry, subentry), unique_id = f"{subentry.subentry_id}_departure_time", _attr_native_value = time(7, 0)
    - `async_added_to_hass()`:
      - Call super().async_added_to_hass()
      - Get last_state = await self.async_get_last_state()
      - If last_state exists and state not in ("unknown", "unavailable"):
        - Try: self._attr_native_value = time.fromisoformat(last_state.state)
        - Except (ValueError, TypeError): pass (keep default)
      - Set self.coordinator.departure_time = self._attr_native_value
    - `async_set_value(self, value: time) -> None`:
      - self._attr_native_value = value
      - self.async_write_ha_state()
      - self.coordinator.departure_time = value
      - await self.coordinator.async_request_refresh()

    Note: TimeEntity uses `async_set_value` not `async_set_native_value` (unlike NumberEntity).
    The RestoreEntity mixin uses `async_get_last_state` (general), not `async_get_last_number_data` (number-specific).
