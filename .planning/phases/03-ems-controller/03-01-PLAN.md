**Dataclasses:**

`EMSDecision` (frozen dataclass):
- `target_mode: str` -- "command_charging" | "max_self_consumption" | "standby"
- `charge_limit_kw: float` -- Safe charging limit in kW
- `fuse_headroom_amps: float` -- Available fuse headroom in amps
- `override_reason: str | None` -- Why mode differs from schedule ("car_charging_priority", "pv_opportunistic", None)

**Class: PVHysteresisTracker:**
Simple state machine to prevent PV charging oscillation.
- States: "off", "pending_on", "on", "pending_off"
- `__init__(self, activate_threshold_w=500, deactivate_threshold_w=300, required_consecutive=2)`
- `update(self, pv_power_w: float) -> bool` -- Returns True if PV charging should be active. Manages state transitions internally with consecutive check counting.
- `@property state -> str` -- Current state for logging/debugging.

State transitions:
- off: pv >= activate_threshold => pending_on (counter=1)
- pending_on: pv >= activate_threshold => counter++; if counter >= required_consecutive => on
- pending_on: pv < activate_threshold => off (reset)
- on: pv < deactivate_threshold => pending_off (counter=1)
- on: pv >= deactivate_threshold => stay on
- pending_off: pv < deactivate_threshold => counter++; if counter >= required_consecutive => off
- pending_off: pv >= deactivate_threshold => on (reset)

**Functions:**

`compute_ems_state(target_ems_mode, current_l_amps, fuse_rating_amps, max_charge_power_kw, battery_soc_pct, car_scheduled, car_plugged_in, pv_power_w, pv_hysteresis_active, max_soc_pct=95.0, safety_buffer_amps=2.0, voltage=230.0) -> EMSDecision`:

Implementation logic (order matters for safety):
1. Calculate fuse headroom: `headroom = max(0.0, fuse_rating_amps - current_l_amps - safety_buffer_amps)`
2. Map "idle" target to "max_self_consumption" (idle = let battery optimize itself)
3. Car priority check (EMS-03): if car_scheduled AND car_plugged_in AND target is "command_charging" => return standby with override_reason="car_charging_priority"
4. Fuse-limited charging power (EMS-02): `headroom_kw = (headroom * voltage) / 1000.0`; `safe_charge_kw = max(0.0, min(max_charge_power_kw, headroom_kw))`
5. PV opportunistic (EMS-08): if target is "standby" or "max_self_consumption" AND pv_hysteresis_active AND battery_soc_pct < max_soc_pct => return command_charging with charge_limit = min(pv_power_w/1000.0, safe_charge_kw), override_reason="pv_opportunistic"
6. Return final EMSDecision with target_mode=mapped mode, charge_limit_kw (only for command_charging, else 0), fuse_headroom_amps=headroom

`clamp_amps(value, min_amps=0.0, max_amps=32.0) -> float`:
- Hard-clamp: `max(min_amps, min(value, max_amps))`
