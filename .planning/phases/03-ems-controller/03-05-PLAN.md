<objective>
Fix the critical fuse protection safety issue: replace balanced-load averaging with per-phase
power monitoring so fuse headroom uses the worst-case (highest) phase current.

Purpose: On unbalanced 3-phase loads, the current system divides total power by 3, masking
dangerous per-phase overloads. With phase A at 30A and B/C at 5A, the system calculates 13.3A
average and allows charging -- when phase A is actually 10A over a 20A fuse. This is a safety
bug that must be fixed.

Output: Per-phase grid power support across const, auto-detect, config flow, coordinator, and
translations. The pure ems_controller.py needs zero changes (already expects highest-phase
current). Total grid power remains as fallback for single-phase installations.
</objective>

    Replace the existing `_read_grid_current_amps()` method entirely with:
    ```python
    def _read_grid_current_amps(self) -> float:
        """Read per-phase grid power and return worst-case phase current in amps.

        If per-phase sensors are configured, reads each phase's power and converts
        to amps independently: I = abs(P_phase) / V_phase. Returns the MAX across
        all three phases (worst-case for fuse protection).

        Falls back to total-power balanced-load estimate if per-phase sensors are
        not configured.

        Returns:
            Highest phase current in amps, or 0.0 if unavailable.
        """
        phase_entities = [
            self._grid_phase_a_entity,
            self._grid_phase_b_entity,
            self._grid_phase_c_entity,
        ]

        if all(phase_entities):
            # Per-phase mode: convert each phase to amps, take worst case
            phase_amps = []
            for entity_id in phase_entities:
                power = self._read_float_state(entity_id, 0.0)
                state = self.hass.states.get(entity_id)
                if state is not None:
                    uom = state.attributes.get("unit_of_measurement", "")
                    if uom == "kW":
                        power = power * 1000.0
                phase_amps.append(abs(power) / 230.0)
            return max(phase_amps) if phase_amps else 0.0

        # Fallback: single total power sensor with balanced-load assumption
        power = self._read_float_state(self._grid_power_entity, 0.0)
        if power == 0.0:
            return 0.0
        state = self.hass.states.get(self._grid_power_entity)
        if state is not None:
            uom = state.attributes.get("unit_of_measurement", "")
            if uom == "kW":
                power = power * 1000.0
        return abs(power) / (3.0 * 230.0)
    ```
