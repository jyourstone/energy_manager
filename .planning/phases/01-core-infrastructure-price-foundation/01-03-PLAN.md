Create `coordinator.py` with the internal-only price data coordinator. This creates NO user-visible entities per user decision -- price data is consumed by downstream modules via `entry.runtime_data.price_coordinator.data`.

**Data structures (at module level):**

`PriceSlot` -- frozen dataclass with `__slots__`:
- `start: datetime` (UTC, timezone-aware)
- `end: datetime` (UTC, timezone-aware)
- `price: float` (SEK/kWh, pass-through from Nordpool)
- Use `@dataclass(frozen=True, slots=True)` for immutability and memory efficiency

`PriceData` -- dataclass:
- `today: list[PriceSlot]` (24 hourly slots for today)
- `tomorrow: list[PriceSlot]` (24 hourly slots or empty list `[]` if not yet available)
- `current_price: float | None` (current hour's price, None if unavailable)
- `last_updated: datetime` (UTC timestamp of last successful update)

**PriceCoordinator(DataUpdateCoordinator[PriceData]):**

`__init__(self, hass, entry)`:
- Call `super().__init__()` with:
  - `name="Energy Manager Prices"`
  - `config_entry=entry`
  - `update_interval=timedelta(minutes=PRICE_UPDATE_INTERVAL_MINUTES)` (5 min from const.py)
  - `always_update=False` (only notify listeners when data actually changes)
- Store `self._nordpool_entity = entry.data[CONF_NORDPOOL_SENSOR]`
- Store `self._nordpool_type = entry.data[CONF_NORDPOOL_TYPE]`

`async _async_setup(self)` -- called once during `async_config_entry_first_refresh`:
- Register Nordpool state change listener for immediate updates:
  ```python
  self.config_entry.async_on_unload(
      async_track_state_change_event(
          self.hass, [self._nordpool_entity], self._on_nordpool_update
      )
  )
  ```
- This ensures the listener is cleaned up automatically on unload

`_on_nordpool_update(self, event)` -- callback decorator `@callback`:
- When Nordpool sensor state changes (e.g., tomorrow's prices arrive ~13:00 CET), trigger immediate refresh
- `self.hass.async_create_task(self.async_request_refresh())`

`async _async_update_data(self) -> PriceData`:
- Call `async_get_prices(self.hass, self._nordpool_entity, self._nordpool_type)` from nordpool_adapter
- If `raw_today` is empty: `raise UpdateFailed("No Nordpool price data available for today")`
- Convert raw dicts to `PriceSlot` objects:
  - For each entry in raw_today/raw_tomorrow: parse `start`/`end` as timezone-aware datetime (handle both ISO string and datetime objects), extract `value` as float
  - If `start`/`end` are strings, use `datetime.fromisoformat()`. If already datetime, use directly.
  - Ensure all datetimes are UTC via `dt_util.as_utc()`
- Get current price from Nordpool sensor state: `float(state.state)` if state exists and is not "unavailable"/"unknown", else `None`
- Return `PriceData(today=today_slots, tomorrow=tomorrow_slots, current_price=current_price, last_updated=dt_util.utcnow())`

**EnergyManagerData** -- runtime data dataclass:
- `price_coordinator: PriceCoordinator`
- `modules_enabled: dict[str, bool]` (module ID -> enabled flag)
- Future phases add coordinators here

**Type alias:**
- `type EnergyManagerConfigEntry = ConfigEntry[EnergyManagerData]`

Import from nordpool_adapter: `async_get_prices`. Import from const: `CONF_NORDPOOL_SENSOR`, `CONF_NORDPOOL_TYPE`, `PRICE_UPDATE_INTERVAL_MINUTES`, `CONF_BATTERY_ENABLED`, `CONF_EV_ENABLED`, `MODULE_BATTERY`, `MODULE_EV`.

Create `__init__.py` implementing the full integration lifecycle. This is the entry point HA calls when the integration loads.

**async_setup_entry(hass, entry: EnergyManagerConfigEntry) -> bool:**

1. Create PriceCoordinator:
   ```python
   price_coordinator = PriceCoordinator(hass, entry)
   await price_coordinator.async_config_entry_first_refresh()
   ```
   If Nordpool sensor is unavailable, `async_config_entry_first_refresh` will raise `ConfigEntryNotReady` automatically via `UpdateFailed` -> HA retries.

2. Store typed runtime data:
   ```python
   entry.runtime_data = EnergyManagerData(
       price_coordinator=price_coordinator,
       modules_enabled={
           MODULE_BATTERY: entry.options.get(CONF_BATTERY_ENABLED, False),
           MODULE_EV: entry.options.get(CONF_EV_ENABLED, False),
       },
   )
   ```

3. Register hub device in device registry:
   ```python
   device_registry = dr.async_get(hass)
   device_registry.async_get_or_create(
       config_entry_id=entry.entry_id,
       identifiers={(DOMAIN, entry.entry_id)},
       name="Energy Manager",
       manufacturer="Energy Manager",
       model="Hub",
       entry_type=dr.DeviceEntryType.SERVICE,
   )
   ```

4. Forward platforms conditionally (Phase 1 has no platforms yet, but the structure must support future phases):
   ```python
   platforms = _get_enabled_platforms(entry)
   if platforms:
       await hass.config_entries.async_forward_entry_setups(entry, platforms)
   ```

5. Return `True`

**_get_enabled_platforms(entry) -> list[Platform]:**
- Build platform list based on enabled modules
- Phase 1: returns empty list (no entity platforms yet)
- Structure: `platforms = []`, then `if entry.options.get(CONF_BATTERY_ENABLED): platforms.extend([...])`, etc.
- This function will be extended in future phases as modules add entities

**async_unload_entry(hass, entry: EnergyManagerConfigEntry) -> bool:**
- Unload forwarded platforms:
  ```python
  platforms = _get_enabled_platforms(entry)
  if platforms:
      return await hass.config_entries.async_unload_platforms(entry, platforms)
  return True
  ```
- Coordinator listeners are auto-cleaned via `entry.async_on_unload()` registered in `_async_setup`
- No manual cleanup needed for runtime_data (garbage collected)

**async_migrate_entry(hass, config_entry) -> bool:**
- Log migration attempt: `_LOGGER.debug("Migrating from version %s.%s", config_entry.version, config_entry.minor_version)`
- If `config_entry.version > CONFIG_VERSION`: return False (can't downgrade from future version)
- Return True (no migrations needed in v1, but the hook must exist for future versions)

**Module-level:**
- `_LOGGER = logging.getLogger(__name__)`
- Import `EnergyManagerConfigEntry`, `EnergyManagerData`, `PriceCoordinator` from `.coordinator`
- Import all needed constants from `.const`
- Import `homeassistant.helpers.device_registry as dr`
