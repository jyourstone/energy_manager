Create `custom_components/energy_manager/sensor.py` with:

1. **`async_setup_entry` function** that receives `hass`, `entry: EnergyManagerConfigEntry`, and `async_add_entities` callback. Gets `entry.runtime_data.price_coordinator` and creates a single `EnergyManagerPriceSensor` entity.

2. **`EnergyManagerPriceSensor`** class that extends `EnergyManagerEntity` from `entity.py`:
   - Pass `price_coordinator` as the coordinator and `entry` to the `EnergyManagerEntity.__init__`
   - `_attr_translation_key = "electricity_price"`
   - `_attr_unique_id = f"{entry.entry_id}_electricity_price"`
   - `_attr_device_class = SensorDeviceClass.MONETARY`
   - `_attr_state_class = SensorStateClass.MEASUREMENT`
   - `_attr_native_unit_of_measurement = "SEK/kWh"` (per context decision: SEK/kWh as-is from Nordpool, pass-through)
   - `_attr_suggested_display_precision = 2`

   **State property (`native_value`):**
   - Return `self.coordinator.data.current_price` if coordinator has data, else `None`

   **Extra state attributes property (`extra_state_attributes`):**
   - Return a dict with three keys:
     - `"today"`: List of dicts, each with `{"start": slot.start.isoformat(), "end": slot.end.isoformat(), "price": slot.price}` for each PriceSlot in `coordinator.data.today`. Empty list if no data.
     - `"tomorrow"`: Same format for `coordinator.data.tomorrow`. Empty list if no data or tomorrow not yet available.
     - `"last_updated"`: `coordinator.data.last_updated.isoformat()` if data exists, else None.

Update `custom_components/energy_manager/__init__.py`:

   - Update docstring of `_get_enabled_platforms` to reflect that Platform.SENSOR is always included for the price sensor.
